# assets — 마스코트 이미지 · 배포용 그림

홈 화면 마스코트(우주비행사 고양이) 이미지를 이 폴더에 넣어주세요.
투명 배경 PNG 권장(밤하늘 위에 자연스럽게 얹힘). 파일명은 아래 그대로.

| 파일명 | 상태 | 언제 표시되나 |
|---|---|---|
| `cat-idle.png` | 기본(평상시) | 한 손 인사 — 평소/진행 중 |
| `cat-happy.png` | 신남 | 오늘 루틴 6개 완주 시 |
| `cat-sad.png` | 시무룩 | 스트릭 끊김 / 며칠 만에 방문 |

- 표시 크기는 132×132 박스에 `object-fit:contain`(비율 유지, 정사각형 아니어도 됨).
- 코드는 이미 이 경로(`assets/cat-idle.png` 등)를 참조합니다 — 파일만 넣으면 동작.


## 배포 메타용 그림 (`make_og.py`가 만든다)

| 파일 | 쓰이는 곳 |
|---|---|
| `og.png` (1200×630) | 링크 공유 미리보기 카드 — `index.html`의 `og:image` |
| `icon-192.png` · `icon-512.png` | `manifest.json` 앱 아이콘 |
| `icon-maskable-512.png` | 안드로이드 — 원형으로 잘려도 별이 안 잘리게 안쪽 22%를 비웠다 |
| `../apple-touch-icon.png` (180×180) | iOS 홈 화면. 알파 없이 저장한다(iOS가 투명을 검게 칠한다) |
| `../favicon.ico` · `../favicon.svg` | 탭 아이콘. svg가 우선, ico는 옛 브라우저용 |

- 저장소 루트에서 `python assets/make_og.py` (Pillow 필요). 같은 그림이 다시 나온다.
- 색은 앱 토큰(`css/app.css`)에서 그대로 가져왔다 — 밤하늘 `#2c3468→#4b5497`, 별빛 `#fff4d2`.
- 아이콘 그림이 고양이가 아니라 별인 이유: 16px에서 마스코트는 뭉개져 아무것도 안 보인다.
