# 오늘의 별자리 — 기획서

> 제품의 "왜/무엇/원칙"을 담는 참고 문서. 코딩 규칙·실행법은 루트 `CLAUDE.md` 참고.

## 한 줄
매일 짧은 손목 운동을 하고, 완주하면 밤하늘에 별자리가 이어지며 금빛으로 빛나는 손목 웰니스 웹앱.

## 문제 / 대상
- 손목이 뻐근하고 뻣뻣한 사람 — 사무직, 반복작업, 손을 많이 쓰는 직군.
- 이들은 "운동해야지"를 알지만 꾸준히 못 한다. 앱은 **훈련·판정이 아니라 습관·돌봄**을 돕는다.

## 목적 / 비목적
- **목적:** 매일 조금씩 손목을 움직이게 하고, 가동범위 변화를 부드럽게 보여준다.
- **비목적:** 진단·처방·물리치료 대체가 아니다. 의료기기가 아니다. 수치로 겁주지 않는다.

## 설계 원칙 (제품의 헌법)
1. **보이는 돌봄** — 모든 문구는 판정·부족·처방이 아니라 진척·응원·중립 정보로.
   "정상인 대비 몇 %" ❌ → "일상 기능 기준 진척률" ⭕. 하락·정체는 부호 없는 추세로만(부정 문구 없음).
2. **고민하게 만들면 안 한다** — 오늘의 루틴은 매일 같은 고정 코스. 선택·설정 마찰 최소화. 원탭 시작.
3. **감정 페이오프** — 루틴 완주 시 오늘의 별자리가 이어지며 금빛으로 빛난다. 완성한 별자리는 밤하늘 도감에 수집.
4. **관대함** — 중간에 그만둬도 그날 완료로 인정. 뻐근한 날은 순한 코스를 "제안"(강제 아님).
5. **프라이버시** — 카메라 분석은 전부 기기 안에서. 영상 저장·전송 없음. 켜기 전 안심 안내로 권한 거부 방지.
6. **접근성** — `prefers-reduced-motion` 존중, 대비 확보, 큰 버튼, 한국어 친화 문구.

## 핵심 기능
### 1) 데일리 루틴 (홈)
- 6종 고정 코스. 홈 카드 상태 3종: 미시작 / 이어하기(부분 완료) / 완주.
- 완주 → 오늘의 별자리 완성 연출(1회) + 도감 누적.
- 부속: 스트릭(연속일) 배지, 우주 고양이 마스코트(표정·말풍선), 알림(최대 3회).

### 2) 가이드 (운동 따라하기)
- 각 운동 = **intro**(준비 자세) → **follow**(카메라 인식하며 N회) → **outro**(마무리).
- 시범 손 애니메이션 + 회전 동작엔 궤적 호(arc). 카메라로 사용자 손을 인식해 회수를 센다.
- 손 인식 실패·보상동작에도 관대(진행을 막지 않음, [건너뛰기] 항상 제공).
- 루틴 모드는 완료 후 다음 운동 자동 연속 재생.

### 3) 손목 체크 (측정)
- 가동범위(ROM) 측정: **굽힘·폄(옆모습)** + **좌우 편위(정면, 선택)**.
- 흐름: 중립 잡기 → 끝범위 유지-캡처(끝에서 잠깐 멈추면 자동 기록). 손 좌우는 사용자가 선택.
- 결과 = **선물 프레이밍**(개선한 체크에만 별 하나 선물, 하루 1회). 지난 대비는 부호 없는 참고값.
- 측정 "제안" 주기 7일 — 제안 문구까지만, 판정 아님.

### 4) 밤하늘 도감
- 완성한 별자리를 하나의 밤하늘에 수집(총 16종). 완성=밝게+이름+일기 카드 / 미완성=흐릿·잠김.

### 5) 기록
- ROM 추이(굽힘·폄 / 편위 합) 라인차트. 루틴·가이드 완료 히스토리, 주간 컨디션.

## ROM 근거 (참고용, 판정 아님)
- **기능적 가동범위 기준:** 굽힘 40° · 폄 40°(일상생활 참고). 편위는 요측+척측 '합' 기준.
- 시범 각도·속도는 코드에 명시(예: 굽힘·폄 옆모습, 편위 정면). `js/guide/guideData.js`.
- 측정은 화면 평면 내 **직접-각도**(길이비율 역산 없음). 손별 거울 보정은 `measurement.js`.
- 편위 개별 요측/척측 라벨은 잠정 — '합' 진척률은 부호와 무관해 안전하게 먼저 노출.

## 톤 & 비주얼
- **밤하늘 인디고 배경 + 금빛 별자리(감정 포인트) + 살구빛 손 + 라벤더/청록 보조색.**
- 문구: 따뜻하고 담백, 이모지 절제.
- (진행 중) UI 완성도 향상: 층 있는 밤하늘(그라데이션+성운+별 반짝), 떠 있는 유리 카드, 글자 대비 강화.

## 용어
- **ROM**: Range of Motion(가동범위).
- **굽힘/폄**: flexion / extension. **요측/척측 편위**: radial / ulnar deviation(엄지쪽/새끼쪽).
- **intro / follow / outro**: 가이드 스텝 유형(준비 / 따라하기 / 마무리).
- **스트릭**: 연속 활동 일수. **도감**: 완성한 별자리 수집 화면.
