# 스모크 체크리스트 — 눈으로만 확인되는 것들

자동 테스트가 못 가는 자리를 모아둔다. 플레인 node 스위트는 DOM·`rAF`·카메라·CSS에
접근하지 못하므로, 그 경계 밖의 동작은 여기 적어두고 배포 전에 한 번씩 눈으로 본다.

**기록에 맡기지 않는 이유:** 이런 항목은 "깨져도 조용하다". 타이머가 2배속으로 흐르거나
권한 프롬프트가 하나 더 뜨는 건 예외도 로그도 남기지 않는다. 목록이 없으면 다음 사람이
(대개 두 달 뒤의 우리) 같은 자리를 다시 발견하는 데 컨텍스트 복원 비용을 낸다.

확인 방법: `python -m http.server 8137` → `http://127.0.0.1:8137/`

> ⚠ 브라우저 자동화로는 `rAF` 기반 동작을 확인할 수 없다. 자동화 탭은
> `document.visibilityState === 'hidden'`이라 `requestAnimationFrame`이 한 번도 안 돈다
> (포커스를 줘도 그렇다). 진행 바가 **차오르고 리셋되는** 것, timed 라운드가 넘어가는 것은
> 사람이 직접 창을 띄워 봐야 한다. 반대로 DOM 존재·레이아웃·`getUserMedia` 호출 여부는
> 자동화로 확인된다 — 아래 체크는 그 경계를 염두에 두고 나눠 적었다.

## 카메라 생명주기

- [x] **timed 전용 가이드 진입 시 카메라 권한 프롬프트가 뜨지 않는다.**
      PIP(`gpPip`)와 안심 안내(`gpPriv`)도 함께 감춰진다.
      · 2026-09-02 확인 — `navigator.mediaDevices.getUserMedia`를 가로채 호출 수를 셌다.
        timed 픽스처 진입 → 0회 / 대조군 pinch_hold 진입 → 1회. PIP도 각각 숨김/노출.
        (프롬프트를 눈으로 보는 대신 호출 자체를 재는 편이 재현 가능해서 이렇게 한다.)
      · 왜 여기 있나: 프레임 구동 경로는 `needsCamera` 한 곳에서만 갈린다. 그 분기가
        깨지면 카메라가 열린다 — 자동 테스트가 `rAF`·권한 API에 못 가서 못 잡는 자리다.
        (분기가 깨져도 두 프레임 루프가 서로를 정지시키므로 타이머 2배속은 구조로 막혀
        있지만, "권한이 뜬다"는 그 방어로도 안 막힌다.)
- [ ] follow 가이드 → timed 가이드 연속 재생 시 앞 운동의 카메라가 꺼진다.
- [ ] timed 가이드 → follow 가이드로 넘어가면 PIP가 다시 보인다.
- [ ] 가이드 화면을 떠나면 카메라 표시등이 꺼진다(백그라운드 점등 없음).

## 유지 진행 바 (`gp-prog`)

- [ ] pinch·grip 유지 중 바가 차오르고, 유지가 끊기면 0으로 돌아간다. **(사람만 확인 가능)**
- [ ] timed 라운드마다 0에서 다시 찬다. **(사람만 확인 가능)**
- [ ] 유지 중이 아닐 때는 바가 아예 안 보인다(빈 바가 남지 않음).
- [x] 힌트·dots와 겹치지 않는다. — 2026-09-02 확인: `gpProg.top 749` >
      `gpHint.bottom 741` > `gpDots.bottom 722`, 폭 220px·높이 6px, 62% 채움 육안 확인.
- [ ] 완료·컨디션 화면에 잔상이 없다.
- [ ] `prefers-reduced-motion: reduce`에서 폭이 튀지 않고 즉시 반영된다.

## 측정 자세 게이트

- [ ] 옆모습 단계에서 손바닥을 카메라로 향하면 중립을 안 잡고 안내가 뜬다.
- [ ] 8초(`VIEW_FIT.relaxMs`) 뒤에는 안내를 접고 진행한다 — 붙잡지 않는다.
- [ ] 중립 카운트다운 도중 자세가 무너지면 카운트다운이 처음부터 다시 시작된다.

## 실측이 필요한 임계값

전부 기하학 추정치라 실기기에서 한 번에 확정한다. `DEBUG_GUIDE`·`DEBUG_MEASURE`를 켜면
콘솔에 프레임마다 값이 찍힌다.

- [ ] `VIEW_FIT.sideMax` (0.45) / `frontMin` (0.60) — 두 값 사이 완충 구간은 경계에서
      게이트가 깜빡이는 걸 막는 히스테리시스다. 실측 후에도 이 구조는 유지할 것.
- [ ] `fingerSpreadDetector`의 `openT` (1.15) / `closeT` (0.95).

## 접근성·표시
